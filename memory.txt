1. The Core Vision: "Calculated Collaboration"
   * The Problem: Standard AI agents are either "predatory" or "naively altruistic."
   * The Solution: MARL environment proving fairness is the optimal strategy for long-horizon survival.
   * Interdependence: Energy Producers vs. Compute Processors; Leontief Utility ($U = \min(E, C)$).

2. The Engine: "Survival Physics"
   * Resource Decay: -1E, -1C per step (The Hunger Mechanic).
   * Synergy Bonus: +12% Compute to the proposer on successful trades.
   * Environmental Shocks: SOLAR_FLARE (-20% E), GRID_FAILURE (-20% C), NORMAL (85%).

3. The Social Lattice: Reputation as Currency
   * Trust Scores: EMA-based (0.0 - 1.0). Currently lacks volume-weighting.
   * Public Ledger: Visible history of the last 10 transactions.
   * LLM Formatter: Converts math/lattice into semantic narratives for reasoning.

4. The "Cohort of Four" Archetypes
   * Agent 0 (Learner), Agent 1 (Bully), Agent 2 (Altruist), Agent 3 (Tit-for-Tat).

5. Second-Order Vulnerabilities (Current Focus)
   * The Multi-Commit Trap: No Escrow allows double-spending, leading to "false" defaults and reputation ruin.
   * Trust Farming: Rewards for trust improvements can incentivize pointless 1-unit wash-trades.
   * Proposer Advantage: 12% bonus only for the proposer creates a race condition lottery.
   * Zombie Agents: Resource depletion without a floor leads to non-participatory "dead" agents.

6. Immediate Technical Roadmap
   * Implement Escrow Layer: Lock resources upon PROPOSE.
   * Volume-Weighted Trust: `alpha_eff = alpha * log1p(volume)`.
   * Prompt Blindness: Remove personality hints from formatting to force mathematical reasoning.
   * Equilibrium Balancing: Implement UBI/Resource Floor to prevent total zombification.

7. Operational Constants
   * T_max = 190.
   * Alpha = 0.2 (Base).
   * Episode Length = 50-100 steps.
